# GitHub Release and Discoverability

## Public release guidance

- use the repository root identity consistently in release titles and tags
- describe the package as a software engineering Agent Skills package
- link to `README.md`, `SKILL.md`, and `docs/platform-compatibility.md`
- mention that core validation is local, deterministic, and offline
- keep screenshots or social preview assets consistent with engineering scope

## Discoverability language

Prefer these phrases in repository metadata and release notes:

- software engineering AI skills
- architecture and repository delivery
- maintainability and refactoring
- testing and release readiness
- frontend implementation and technical SEO engineering

Avoid language that implies:

- executive role-play
- product strategy ownership
- marketing planning ownership
- live platform certification
