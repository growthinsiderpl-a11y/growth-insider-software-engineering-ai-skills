# Repository Semantic Audit

## Identity

- package id: `growth-insider-software-engineering-ai-skills`
- title: `Growth Insider Software Engineering AI Skills`
- version: `1.0.0-rc.1`
- status: `release-candidate`
- website: [https://growthinsider.pl/en/](https://growthinsider.pl/en/)

## Audit findings

- repository naming, manifest identity, and folder identity are aligned
- software engineering ownership is narrow and explicit
- product strategy, discovery, prioritization, and marketing planning are retired or routed away
- philosophy and evidence classes are embedded across the skill entry and references
- tools are deterministic and explainable rather than score-driven
- public package metadata, governance docs, adapters, tests, and workflows are present

## Semantic risks explicitly avoided

- claiming Growth Insider invented established engineering literature
- republishing long book-like prose instead of operational procedures
- collapsing marketing, product, and engineering into one generic bundle
- presenting local validators as proof of live model behavior
