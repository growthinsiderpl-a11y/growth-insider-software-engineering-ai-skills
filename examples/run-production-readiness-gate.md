# Run Production Readiness Gate

Example request:

> Run a production-readiness gate for a release that includes a schema migration, feature flag, and operator dashboards.

Expected response shape:

- frame the software problem and constraint
- label facts, assumptions, and unknowns
- route to the smallest relevant hub and playbook
- include deterministic tool use only if it materially clarifies the answer
- close with validation, measurement, review timing, and any cross-skill handoff
